
## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npx expo start
   ```



## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```



## Running the backend

```

# First install dependencies

cd express-server
npm install
npm run dev

cd ../flask-server
python -m venv venv

source venv/bin/activate        # linux/mac/git-bash
.\venv\Scripts\activate         # windows

pip install -r requirements.txt
python src/app.py
```
